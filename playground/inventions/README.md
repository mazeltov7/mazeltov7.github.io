# 発明の年表

世界の84の発明・技術を、6分野と年代から探索する静的ページ。
既存のPlaygroundと同じく、ビルド不要のHTML・CSS・Vanilla JSで動作する。

## 起動・検証

リポジトリのルートで `python3 -m http.server 8889` を実行し、
`http://localhost:8889/playground/inventions/` を開く。

`node --test playground/inventions/timeline.test.mjs` でデータの参照整合性、
年代境界、検索、代表表示と絞り込み、URL復元を検証する。

## 構成

- `index.html`：ページの構造、読み方、読み込み失敗時の表示
- `styles.css`：既存サイトのパレットを使ったレスポンシブ表示
- `app.js`：DOMの描画、検索、詳細と関連項目の探索
- `timeline.mjs`：年代区分・絞り込み・URL状態
- `data.json`：収録項目、出典、関係

PCの初期表示は分野×時代、スマホは年代順の一覧。
初期表示では代表44件を表示し、全件チェック、検索、分野・時代の指定で
残りの項目へアクセスする。PCでは年代順の一覧へも切り替えられる。
「ほかN件」は、そのセルの中で追加項目を開閉する。分野・時代・URLは変えず、
詳細を開閉しても展開状態を保持する。「条件をリセット」で展開状態も戻す。
開閉は短いアニメーションで表示し、動きを減らす設定ではアニメーションしない。
全体の列幅は期間に比例しない。時代を選ぶと年代区分を細分化する。

## データの編集方針

各項目の `year` は並び替え・年代区分のための代表値。
画面では `dateLabel` と `dateKind` を必ず使う。先史の「年前」は概数で、
`year` を厳密な西暦換算として表示しない。幅のある年代も代表値で配置する。

`outcome` はできるようになったこと、`mechanism` は仕組みの要点、
`caveat` は年号・帰属・実用化段階の留意点。発見、試作、特許、実用化、
普及を混同しない。長期的に成立した技術には無理に発明者を割り当てない。

`sources` は博物館、図書館、学協会、原著論文、開発機関などを中心にする。
既存の人類知マップの文言や年号は自動転用せず、出典と照合している。
出典URLだけでなく、タイトル、年代の意味、説明の裏付けを確認して更新する。

`relations` には出典を添え、直接の改良・利用と「同じ課題」「共通する基盤」を
ラベルで区別する。年代が前後するというだけで因果関係とはしない。
直接の伝播が不確かな活字印刷の地域間関係などは、断定しない旨を添える。

件数を変更したら、Playgroundカードの紹介文とデータ検証の期待値も更新する。
新しい時代を収録したら `timeline.mjs` の年代範囲も確認する。

## 共有

`?id=watt&all=1` のようなURLで個別の発明を開ける。
検索条件・分野・時代・表示形式もURLに記録する。画像OGPはサイト共通で、
発明ごとにクローラー向けHTMLを生成する構成ではない。
