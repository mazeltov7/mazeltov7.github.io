# 時代別の人類知マップ

`period.html?id=meiji-ww2` は1850〜1945年の209項目を探索するページです。
ビルドや外部ライブラリは不要です。JSONを取得するため、ファイルを直接開かずHTTPサーバーで表示します。

## ローカル確認

リポジトリのルートで実行します。

```sh
python3 -m http.server 8891 --bind 127.0.0.1
```

[確認ページ](http://127.0.0.1:8891/playground/knowledge-map/period.html?id=meiji-ww2)

主な確認手順：

1. 「漱石」を検索し、1905〜1915年の12作品へ表示が移ることを確認。
2. 『こゝろ』の詳細で発表年・舞台年代・出典を確認し、「作品の背景」の大正改元へ移動。
3. 全期間で「My Booksを重ねる」「読んだ本だけ」を選び、32冊・36項目（別途、原典の関連書2冊）と書籍ページへのリンクを確認。
4. 年表の単独項目・まとまり・一覧から詳細を開き、閉じると元の項目にフォーカスが戻ることを確認。スマートフォン幅の詳細でも同様に確認。

## ファイル構成と編集

- `period.html` / `period.css`：画面の構造と表示。
- `period.js`：検索、期間選択、詳細、URL状態、読書記録の表示。
- `period-model.mjs`：DOMに依存しない検索・年代・読書の照合・関連項目の規則。
- `periods/meiji-ww2.json`：年表の基本データ209項目。
- `periods/meiji-ww2.details.json`：既存の詳しい解説。
- `periods/meiji-ww2.explore.json`：出典、追加解説、明示した関係、書籍の対応表。

`explore.json` の空の `courses` 配列は、キャッシュに残った旧画面との互換性のために保持します。

追加解説は既存の詳細に項目単位で重ねます。出典・解説を補完した対象は39項目です。残る項目は従来の解説を表示し、出典未整理であることを示します。全209項目の内容を再検証したものではありません。

「影響関係」「作品の背景」は根拠とともに明示した関係です。「同時代」は近い年代の別分野から、「共通するテーマ」は一致するテーマから候補を選びます。同時期やテーマの一致だけでは因果関係と扱いません。

読書記録は `../my-books/books-data.json` から読みます。原著発行年で配置し、読了年は詳細に別表示します。同じ作品の対応は `bookLinks` の書名と著者を照合し、既存年表の年を変更しません。たとえば『行人』は年表の1913年とMy Booksの原著発行年1914年を、それぞれの記録として保持します。現在は32冊の読書記録を年表の29作品と、読書レーンの7項目へ接続しています。合本は同じ書名・著者で複数の `bookLinks` を持てます。『文鳥・夢十夜』は2作品へ、『城の崎にて・小僧の神様』は1917年と1920年の2作品へ接続し、冊数は書籍IDで一度だけ数えます。再読は読了年ごとの記録を保持します。合本の詳細では収録元へのリンクを示し、個々の初出年は作品の欄に表示します。

## 検証

```sh
node --input-type=module --check < playground/knowledge-map/period.js
node --test playground/knowledge-map/period-model.test.mjs
git diff --check
```

19件の自動テストで、期間の端・継続期間・全件の保持・検索の表記揺れ・書籍の誤照合防止・合本と再読の重複防止・原典と解説書の区別・関係と出典の参照整合を確認します。ブラウザでは検索、My Booksの重ね合わせ、合本から各作品への接続、初出年と読了年の表示、PC・スマートフォン幅の詳細表示を確認します。

## 2026年10月の読書追加

全体マップは112項目。前回・今回追加した計10冊を、作品・原著の発表／刊行年で登録しています。合本は代表的な収録作品ごとに配置し、同じ読書記録へ接続します。今回追加した『阿部一族・舞姫』は『阿部一族』『舞姫』と既存項目の『うたかたの記』、『山椒大夫・高瀬舟』は表題の2作品を扱います。合本の全収録作品を網羅したものではありません。

全体マップの `data.json` にも `bookLinks` を持ち、詳細からMy Books、原典と解説書、出典へ進めます。『友情』は年表では連載開始1919年、My Booksでは単行本刊行1920年です。『定本 日本近代文学の起源』は原著1980年に置き、2008年の文庫版と区別します。

明示的な対応表は原著年の自動配置より優先します。年が未設定の合本も接続できます。`kind: "commentary"` の解説書は `relatedBookRecords` に保持し、原典を読了扱いにしません。西田の原典（1911年）の詳細から藤田（2022年）・若松（2025年）の2冊を確認できます。「読んだ本だけ」には原典を含めず、冊数も32冊と関連書2冊を分けて表示します。

追加確認：全体マップで10冊の題名を検索しMy Booksリンクを確認。近代ビューで『友情』『阿部一族』『高瀬舟』の初出と合本リンク、および『善の研究』の関連書を確認。
