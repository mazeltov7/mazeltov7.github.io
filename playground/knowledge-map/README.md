# 時代別の人類知マップ

`period.html?id=meiji-ww2` は1850〜1945年の196項目を探索するページです。
ビルドや外部ライブラリは不要です。JSONを取得するため、ファイルを直接開かずHTTPサーバーで表示します。

## ローカル確認

リポジトリのルートで実行します。

```sh
python3 -m http.server 8891 --bind 127.0.0.1
```

[確認ページ](http://127.0.0.1:8891/playground/knowledge-map/period.html?id=meiji-ww2)

主な確認手順：

1. 「漱石」を検索し、1905〜1914年の6作品へ表示が移ることを確認。
2. 『こゝろ』の詳細で発表年・舞台年代・出典を確認し、「作品の背景」の大正改元へ移動。
3. 「問いからたどる」を開き、3つのガイドを前後に進む。
4. 全期間で「My Booksを重ねる」「読んだ本だけ」を選び、24冊と書籍ページへのリンクを確認。
5. 年表の単独項目・まとまり・一覧から詳細を開き、閉じると元の項目にフォーカスが戻ることを確認。スマートフォン幅の詳細でも同様に確認。

## ファイル構成と編集

- `period.html` / `period.css`：画面の構造と表示。
- `period.js`：検索、期間選択、詳細、ガイド、URL状態、読書記録の表示。
- `period-model.mjs`：DOMに依存しない検索・年代・読書の照合・関連項目の規則。
- `periods/meiji-ww2.json`：年表の基本データ196項目。
- `periods/meiji-ww2.details.json`：既存の詳しい解説。
- `periods/meiji-ww2.explore.json`：探索ガイド、出典、追加解説、明示した関係、書籍の対応表。

追加解説は既存の詳細に項目単位で重ねます。出典・解説を補完した対象は、ガイドの全18項目を含む22項目です。残る項目は従来の解説を表示し、出典未整理であることを示します。全196項目の内容を再検証したものではありません。

「影響関係」「作品の背景」は根拠とともに明示した関係です。「同時代」は近い年代の別分野から、「共通するテーマ」は一致するテーマから候補を選びます。同時期やテーマの一致だけでは因果関係と扱いません。

読書記録は `../my-books/books-data.json` から読みます。原著発行年で配置し、読了年は詳細に別表示します。同じ作品の対応は `bookLinks` の書名と著者を照合し、既存年表の年を変更しません。たとえば『行人』は年表の1913年とMy Booksの原著発行年1914年を、それぞれの記録として保持します。現在は24冊中13冊を既存作品に接続し、11冊を読書のレーンに追加しています。

## 検証

```sh
node --input-type=module --check < playground/knowledge-map/period.js
node --test playground/knowledge-map/period-model.test.mjs
git diff --check
```

14件の自動テストで、期間の端・継続期間・全件の保持・検索の表記揺れ・書籍の誤照合防止・関係と出典の参照整合を確認します。ブラウザでは検索と解除、詳細からの移動、戻る・再読み込み、全18ガイドステップ、My Booksの24冊、検索0件・分野0件・不正な年入力からの復帰、PC・800px・390px・360pxの表示、スマートフォン詳細のフォーカス移動とEscapeでの閉鎖を確認しました。
